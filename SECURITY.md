# Security Policy

Please do not open public issues containing secrets, private data, exploit details, live trading credentials, or customer information.

This project intentionally excludes production execution hooks from public repositories. Public demos must be local, toy, and non-executing by default.

Report sensitive findings privately to `373743743@qq.com`. Send only the affected public component, impact category, and a safe way to request details. Do not include credentials, private logs, customer material, or exploit chains in the first message.

This reporting route does not authorize testing third-party systems, production services, customer environments, accounts, or private infrastructure.
