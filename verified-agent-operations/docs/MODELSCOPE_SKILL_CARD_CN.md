# 魔搭 Skills 作品卡

## 作品名

证据到行动许可门：Agent 行动闸门

## 一句话介绍

一个不依赖大模型的本地验证 Skill：把 Agent 的下一步明确分为行动、等待、追问或拒绝，并在证据不足时阻止“猜着做”。

## 作品简介（提交稿，约 250 字）

很多 Agent 的风险不在于不会生成文字，而在于证据不足时仍然把推测变成行动。本作品提供一个可本地运行的“证据到行动许可门”：用户提交包含决策、主张、证据列表和边界的结构化案例，验证器只输出 ACT、WAIT、QUERY、REFUSE 四种明确状态。ACT 必须至少列出一条证据；缺少来源或边界时，系统会拒绝或要求补充。作品不调用外部模型、不访问网络、不执行交易或设备控制，适合用于开发流程中的前置检查、Agent 工作流测试和教学演示。代码、合成样例、失败关闭测试和许可证均公开，方便开发者复制、修改和扩展。它不是事实裁判、生产授权器或安全认证系统，真实业务仍需接入自己的证据源、权限系统和人工审批。

## AI 模型说明

本作品的核心验证器不调用 AI 模型；它是依赖自由的本地 Python 验证器。用户可以在外层工作流中自行接入模型，但模型输出不被本作品视为证据，也不会被自动授权为真实行动。
