# 魔搭 Skills 作品卡

## 作品名

证据到行动许可门：Agent 行动闸门

## 一句话介绍

一个本地两层验证 Skill：可选的本地模型只生成候选证据包，确定性验证器把 Agent 的下一步明确分为行动、等待、追问或拒绝，并在证据不足时阻止“猜着做”。

## 作品简介（提交稿，约 250 字）

很多 Agent 的风险不在于不会生成文字，而在于证据不足时仍然把推测变成行动。本作品提供一个可本地运行的“证据到行动许可门”：可选的本地 Ollama 模型从本地文本生成候选主张、证据、边界和不确定项，默认输出 QUERY 并要求人工复核；确定性验证器再处理显式的 ACT、WAIT、QUERY、REFUSE 状态。模型输出不会自动成为证据，ACT 必须至少列出一条证据；缺少来源或边界时，系统会拒绝或要求补充。作品不访问外部网络、不执行交易或设备控制，适合用于开发流程中的前置检查、Agent 工作流测试和教学演示。代码、合成样例、失败关闭测试和许可证均公开，方便开发者复制、修改和扩展。它不是事实裁判、生产授权器或安全认证系统，真实业务仍需接入自己的证据源、权限系统和人工审批。

## AI 模型说明

核心验证器是依赖自由的本地 Python 验证器。可选适配器只允许调用绑定在 localhost 的 Ollama 模型，用于生成候选证据包；它不接受远程端点，不把模型输出视为事实证据，也不会自动授权真实行动。提交 ModelScope 前，还需要在真实的生产力 Agent 工具中完成调用并保存可复核的录屏和日志。
