# 公开发布边界

## 这是什么

这是一个面向开发者的最小公开原型：它把“证据是否足以支持下一步动作”变成可检查的输入和四种显式状态：`ACT`、`WAIT`、`QUERY`、`REFUSE`。示例只使用合成材料，验证器不调用模型、不联网，也不产生外部副作用。

## 公开内容

- `gate.py`：字段校验和四状态输出。
- `examples/`：合成输入样例。
- `tests/`：失败关闭和字段校验测试。
- 本目录的说明和许可证。

## 不在公开包内

下列内容不得加入这个仓库、演示页、比赛表单附件或公开截图：

- 私有提示词、答案键、供应商回复、账户/计费回执和内部终端验证器。
- 客户数据、个人信息、真实责任链、生产编排、部署阈值和未公开权重。
- 尚未完成权属、许可、作者授权或证据闭环的论文材料。
- 真实交易、机器人、道路、医疗或安全认证结论。

## 允许的主张

可以说：原型能验证结构、强制显式边界、在缺字段时拒绝或请求补充，并能由本地测试复跑。

不能说：原型证明事实为真、达到安全认证、达到 SOTA、适合生产部署、降低了真实事故率，或代表全部研究矩阵。

## 新增文件前的四问

1. 输入能否完全由合成材料构成？
2. 许可证是否已核验并允许公开？
3. 文件是否不包含密钥、个人信息、客户材料和内部路径？
4. 是否有一个可复跑的测试或明确的人工审核步骤？

任何一问不能回答“是”，就停留在私有准备区，不进入公开包。
