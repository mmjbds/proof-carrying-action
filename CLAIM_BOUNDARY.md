# Claim Boundary

Proof-Carrying Action is a minimal public protocol for deciding whether a high-risk AI recommendation has enough evidence to become an action.

## Supported Claims

- The toy demo separates recommendation, repair intent, proof closure, and action permission.
- No-credit repair work does not increase action authority.
- Missing receipts can block action without being treated as a system failure.
- Synthetic proof packets can be checked locally without external services.

## Unsupported Claims

- This repository does not trade.
- This repository does not connect to robots, brokerages, customer systems, or production agents.
- This repository does not claim that any real-world AI system is safe to deploy.
- This repository does not publish private financial traces, execution certificates, or commercial action gates.

## Correct Use

Use this repository to inspect the protocol, run the toy proof-envelope demo, submit failure cases, and build domain-specific adapters.
