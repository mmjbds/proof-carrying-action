# Evidence Ladder

1. Recommendation: a model proposes an action.
2. Warrant: the action has a thesis, falsifier, risk gate, and scope.
3. Receipts: entry, exit, wait-policy, terminal, and counterfactual evidence are closed.
4. Null arms: the action beats required baselines.
5. Regret attribution: outcome can be compared to alternatives.
6. Clean learning: updates are admitted only if provenance is clean.
7. Authority: action permission is granted only after closure.

Repair work may help close gaps, but repair intent is not evidence of success.
